# HomeWindow 0.5.13

- **Graph of the house's use on the taskbar widget.** Hold the mouse over the taskbar widget and the tooltip now also shows a small graph of the house's use over the last hour. Settings → Appearance → **Graph on hover** sets the period (15 minutes, 1 hour, 3 hours) or switches it off. The graph starts when HomeWindow starts.
- **Choose which home batteries count.** If Homey has more than one device marked as a home battery, HomeWindow added up their power and averaged their charge, so the taskbar widget and the Overview could show a charge that matched none of them. With two or more, the Energy page now has **Battery counts from**, like **Solar counts from**, where you switch off the ones that should not count.
- **More detail in the diagnosis for the taskbar widget.** When HomeWindow cannot find the program buttons on the taskbar, the report now lists the windows inside the taskbar, so a taskbar tool that moves the Start button or the icons can be recognised.
