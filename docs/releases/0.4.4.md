# HomeWindow 0.4.4

- **Grid meters are no longer added together.** If you have more than one meter on the same supply, such as a P1 reader and a smart meter, HomeWindow used to add their readings up and showed too much power. It now uses one meter as the grid: it picks the best one itself, and with two or more meters the Energy page has a **Meter for the grid** choice. The kWh totals use the same meter.
- **The list of devices using power follows Homey Energy.** A device that Homey Energy leaves out is no longer counted here either.
- **Collapse all and Expand all on the Flows page**, like on the Devices page.
