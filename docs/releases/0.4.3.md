# HomeWindow 0.4.3

- **Sign in with your Homey account.** Adding a Homey no longer needs an API key: Settings → Homey → **Sign in to Homey…** opens Homey's sign-in page in your browser, and HomeWindow then fills in your Homey by itself. Only an encrypted key to reconnect is kept, never your password. This also works for a Homey that cannot create API keys, such as the Homey Pro (Early 2019). A few parts still need an API key, because Athom does not give those rights to apps that sign in with an account: the system page, updates, restarting apps, deleting notifications and the weather. A Homey you already added keeps its API key.
- **A clearer message when a firewall or virus scanner blocks the connection** to your Homey, instead of a Windows socket error.
- When the connection test fails, it now also shows what Homey itself says, such as a missing permission.
