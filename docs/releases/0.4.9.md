# HomeWindow 0.4.9

- **Send diagnostics.** Settings → About → **Send diagnostics…** writes a report (version, settings, every device with its capabilities, the end of the log) to a file, and opens an e-mail or a GitHub issue to attach it to. It holds no keys, tokens or addresses, but it does hold the names of your devices.
- **EV charger start/stop button, also when Homey names another quick action.** If Homey gave a charger a quick action that is not a switch, its tile had no button. HomeWindow now falls back to the charger's start/stop charging switch.
