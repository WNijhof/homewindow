# HomeWindow 0.5.4

- **Camera pictures show up.** HomeWindow looked for a camera's picture in the wrong place, so the Camera pictures section on the Overview never appeared. It now finds the picture through the camera device, as the Homey app does.
- **Your own icons from Homey.** With *Icons from Homey* on, a device whose icon you changed in the Homey app showed the standard icon. It now shows the one you picked.
- **Diagnostics** list per device how many camera pictures and icon addresses it has.
