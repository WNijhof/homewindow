# HomeWindow 0.5.11

- **Typed text in search boxes starts where the hint text was.** It began about 30 pixels further to the right, because the padding of every text box was applied twice. Other text boxes and the PIN box lose the same extra space on the left and right.
- **Taskbar widget and program buttons:** the search for taskbar buttons now also finds program buttons that Windows does not report as plain buttons, and falls back to a full walk of the taskbar when it finds neither Start nor any program. This is meant for a widget that covered a program button on a recent Windows build.
- **Diagnostics:** the report now says how many program buttons were found and, when none were, which kinds of elements the taskbar showed instead.
