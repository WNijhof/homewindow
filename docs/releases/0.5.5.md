# HomeWindow 0.5.5

- **Taskbar widget stays at the left.** With the biggest consumers on, the widget no longer fitted in the room left of a centred Start button and jumped to the right. It now stays at the left and shows as many of the biggest consumers as fit there (three, two, one or none). Each consumer has a fixed width, so the widget no longer grows and shrinks as the names and power change.
